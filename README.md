# پایگاه دانش هوش مصنوعی بیت‌کوین

این مخزن برای تبدیل ویدیوهای آموزشی تحلیل بیت‌کوین به یک پایگاه دانش **ساختاریافته، قابل‌ردیابی و قابل‌ارزیابی** ساخته شده است.

هدف پروژه این است که هوش مصنوعی بتواند:

1. نکات آموزشی و قواعد تحلیلی را از متن و تصاویر ویدیوها استخراج کند.
2. قواعد عمومی را از تحلیل‌های وابسته به تاریخ و قیمت همان روز جدا کند.
3. برای هر قاعده، منبع، تایم‌استمپ و شواهد قابل بررسی نگه دارد.
4. ابهام‌های متن، خطاهای تبدیل صوت به متن و وابستگی‌های تصویری را ثبت کند.
5. تعارض میان ویدیوها یا روش‌های تحلیلی را پنهان نکند.
6. هنگام تحلیل جدید، نتیجه را به قواعد تأییدشده و داده‌های فعلی متصل کند.
7. عملکرد قواعد را بدون استفاده از اطلاعات آینده ارزیابی کند.

## خروجی نهایی پروژه

خروجی این مخزن صرفاً خلاصه چند ویدیو نیست. هدف، ساخت یک زنجیره قابل ممیزی برای تحلیل بیت‌کوین است:

```text
Source
  ↓
Raw Transcript
  ↓
Reusable Knowledge
  ↓
Current Market Data
  ↓
Analysis Conclusion
  ↓
Evaluation
```

هر نتیجه مهم در تحلیل نهایی باید مشخص کند از کدام `Source ID`، کدام تایم‌استمپ و در صورت وجود از کدام `Rule ID` به دست آمده است.

## این پروژه چه چیزی نیست؟

این مخزن:

- تضمین‌کننده سود یا نتیجه معامله نیست.
- منبع سیگنال قطعی خرید و فروش نیست.
- جایگزین بررسی مستقل داده‌های بازار نیست.
- مجاز به ثبت، تغییر یا لغو سفارش واقعی در OKX یا هر صرافی دیگر نیست.
- سطوح تاریخی حمایت، مقاومت، هدف یا ابطال را به‌عنوان سطوح دائمی بازار نگهداری نمی‌کند.
- به‌تنهایی مدل هوش مصنوعی را Fine-tune یا از نو آموزش نمی‌دهد.

سطوح قیمت و سناریوهای مطرح‌شده در ویدیوهای قدیمی فقط باید به‌عنوان **مثال تاریخی** ثبت شوند و نباید بدون داده تازه بازار در تحلیل امروز استفاده شوند.

## ساختار مخزن

```text
.
├── README.md
├── AGENTS.md
├── .github/
│   ├── CODEOWNERS
│   └── pull_request_template.md
├── transcripts/
│   ├── README.md
│   └── SRC-XXXX.md
└── knowledge/
    ├── rules.md
    ├── glossary.md
    ├── historical_examples.md
    ├── ambiguous_items.md
    ├── conflicts.md
    ├── sources.md
    └── evaluations.md
```

`SRC-XXXX.md` فقط نمونه نام‌گذاری برای فایل‌های Transcript آینده است و الزاماً به معنی وجود یک فایل ثبت‌شده فعلی نیست. قرارداد دقیق ایجاد و نگهداری Transcriptها در [`transcripts/README.md`](transcripts/README.md) تعریف شده است.

## فایل‌های حاکمیتی

### [`AGENTS.md`](AGENTS.md)

قوانین سراسری عامل‌های هوش مصنوعی را تعریف می‌کند؛ از جمله ترتیب اولویت اسناد، فایل‌های لازم برای مطالعه، محدودیت‌های ویرایش، الزامات اعتبارسنجی و قیود ایمنی. README فقط نقش این فایل را توضیح می‌دهد و جزئیات اجرایی آن را تکرار نمی‌کند.

### [`transcripts/README.md`](transcripts/README.md)

قرارداد عملیاتی محلی برای همه فایل‌های داخل `transcripts/` است. نام‌گذاری، metadata، تایم‌استمپ، نگهداری متن خام، محدودیت‌های حق نشر و کنترل نهایی Transcriptها در همان فایل تعریف شده‌اند و در README ریشه تکرار نمی‌شوند.

### [`.github/pull_request_template.md`](.github/pull_request_template.md)

قالب رسمی توضیحات و خلاصه کامل Pull Request در این مخزن است. هنگام ساخت PR باید به همین فایل رجوع شود و README نباید عنوان‌ها، ترتیب یا دستورهای کامل قالب را بازنویسی کند.

### [`.github/CODEOWNERS`](.github/CODEOWNERS)

مسئول یا مالک بازبینی مسیرهای مخزن را مشخص می‌کند. وجود `CODEOWNERS` به‌تنهایی ادغام Pull Request را مسدود نمی‌کند؛ مسدودشدن ادغام فقط زمانی رخ می‌دهد که Code Owner review از طریق GitHub Ruleset یا Branch Protection فعال شده باشد.

## فایل‌های دانشی

- [`knowledge/sources.md`](knowledge/sources.md): رجیستری منابع و وضعیت پردازش آن‌ها.
- [`knowledge/rules.md`](knowledge/rules.md): محل ثبت قواعد تحلیلی عمومی و قابل‌استفاده مجدد.
- [`knowledge/glossary.md`](knowledge/glossary.md): تعریف اصطلاحات استاندارد پروژه.
- [`knowledge/historical_examples.md`](knowledge/historical_examples.md): مثال‌ها، پیش‌بینی‌ها و سطوح وابسته به تاریخ مشخص.
- [`knowledge/ambiguous_items.md`](knowledge/ambiguous_items.md): ابهام‌های Transcript، وابستگی‌های تصویری و موارد نیازمند بازبینی.
- [`knowledge/conflicts.md`](knowledge/conflicts.md): تعارض‌های میان منابع، قواعد یا برداشت‌ها.
- [`knowledge/evaluations.md`](knowledge/evaluations.md): روش‌ها و نتایج ارزیابی استخراج دانش و کاربرد تاریخی قواعد.

جزئیات schema، وضعیت‌های مجاز، قالب ثبت و معیارهای اختصاصی هر فایل باید از همان فایل خوانده شود.

## روند کلی تبدیل ویدیو به دانش

```text
ویدیو
  ↓
ثبت Source ID در knowledge/sources.md
  ↓
ذخیره یا ارجاع Transcript طبق transcripts/README.md
  ↓
استخراج مشاهده، اصطلاح، مثال تاریخی یا قاعده پیشنهادی
  ↓
بررسی منبع، تایم‌استمپ و وابستگی تصویری
  ↓
بازبینی انسانی
  ↓
ثبت دانش در فایل رسمی مربوطه
  ↓
کاربرد محتاطانه در تحلیل جدید
  ↓
ارزیابی در knowledge/evaluations.md
```

یک مشاهده یا مثال منفرد نباید بدون شواهد کافی به قاعده عمومی تبدیل شود. ادعاهای وابسته به نمودار، رنگ، فلش، سطح قیمت یا مقدار روی صفحه باید به‌عنوان وابسته به بررسی تصویری ثبت شوند.

## اصول ایمنی و مرزهای پروژه

- این مخزن برای آموزش، پژوهش و مستندسازی دانش استخراج‌شده از منابع ویدیویی است.
- هیچ قاعده‌ای صرفاً به‌دلیل وجود در مخزن، سیگنال قطعی یا توصیه مالی محسوب نمی‌شود.
- هیچ قابلیت ثبت، تغییر یا لغو سفارش واقعی در OKX یا صرافی دیگر در این مخزن فعال نیست.
- هیچ کلید API، رمز عبور، عبارت بازیابی، private key یا اطلاعات محرمانه نباید در مخزن ذخیره شود.
- قیمت‌ها، حمایت‌ها، مقاومت‌ها، اهداف و سناریوهای قدیمی فقط در زمینه تاریخی همان منبع معتبرند و خودکار به سطح فعلی بازار تبدیل نمی‌شوند.

## وضعیت فعلی

- معماری اصلی مخزن ایجاد شده است.
- قرارداد محلی Transcript در [`transcripts/README.md`](transcripts/README.md) فعال است.
- قالب Pull Request در [`.github/pull_request_template.md`](.github/pull_request_template.md) فعال است.
- فایل [`.github/CODEOWNERS`](.github/CODEOWNERS) وجود دارد.
- مسئولیت‌های Single Source of Truth در این README تعریف و به فایل‌های رسمی لینک شده‌اند.
- در [`knowledge/sources.md`](knowledge/sources.md) هنوز هیچ منبعی ثبت نشده است.
- در [`knowledge/rules.md`](knowledge/rules.md) هنوز هیچ قاعده تحلیلی ثبت نشده است.
- هیچ قاعده‌ای صرفاً به‌دلیل ثبت در مخزن، آماده استفاده برای معامله واقعی نیست.
- هیچ اجرای خودکار سفارش در OKX یا هیچ صرافی دیگری فعال نشده است.

این README ادعا نمی‌کند که GitHub Rulesets، Branch Protection، اعتبارسنجی خودکار GitHub Actions یا الزام Code Owner approval فعال هستند؛ چنین وضعیت‌هایی باید فقط از شواهد قابل‌دسترسی در خود مخزن یا تنظیمات GitHub تأییدشده گزارش شوند.
