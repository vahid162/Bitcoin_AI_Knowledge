# واژه‌نامه

این فایل تعریف استاندارد اصطلاحات مورد استفاده در پروژه را نگهداری می‌کند. واژه‌های استخراج‌شده از Transcript تا زمان بازبینی، اصطلاح تأییدشده محسوب نمی‌شوند.

## وضعیت اصطلاح

- `candidate`: تعریف اولیه
- `verified`: تعریف بازبینی‌شده
- `ambiguous`: معنی یا املای نامطمئن
- `deprecated`: اصطلاح یا تعریف قدیمی

## قالب ثبت اصطلاح

```text
Term ID:
Canonical term:
Persian equivalent:
Aliases and transcript variants:
Category:
Definition:
What it does not mean:
Interpretation notes:
Source IDs:
Status:
Requires visual review: true | false
Last reviewed:
```

## قواعد واژه‌نامه

- املای نامطمئن نباید بدون ثبت نسخه خام اصلاح شود.
- تعریف یک مدرس نباید به‌عنوان تعریف رسمی صنعت معرفی شود، مگر با منبع مستقل.
- اصطلاحاتی که در منابع مختلف معنی متفاوت دارند باید دارای یادداشت تعارض باشند.
- جهت و مقدار شاخص‌ها باید از تعریف خود شاخص جدا ثبت شوند.
